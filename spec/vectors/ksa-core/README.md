# KSA core test vectors

Generated by `generate.py`; consumed by SPEC-0002 Appendix A and SPEC-0003
Appendix A. **Do not edit `vectors.json` or `vectors.md` by hand.**

```sh
python3 -m venv .venv && .venv/bin/pip install cbor2 cryptography
.venv/bin/python generate.py
```

- Signing and hashing come from `cryptography`; no primitive is implemented here.
- Every positive vector is encoded twice — `cbor2` canonical mode and the
  independent `ksa_cbor()` encoder — and the script aborts if they disagree.
- Keys come from fixed seeds; Alice and Bob are the RFC 8032 §7.1 TEST 1 and
  TEST 2 keys, so their public keys can be checked against the RFC.
- Ed25519 is deterministic, so regenerating yields identical bytes.

## Threshold form and the acceptance test

`k` is `threshold` and `n` is the length of `trusts` (`ARCH-0001` §7; §8.6 of
SPEC-0002 calls the threshold `n`, and means `k`).

| vector | case | expected |
|---|---|---|
| TV-9, TV-10, TV-11 | 2 of 3; `k = n`; `k = 1` | verified |
| N-7 | `k = 0` | V8 `kind-rule` |
| N-8 | `k > n` | V8 `kind-rule` |
| N-9 | `n ≠ len(members)`, as an added field | V7 `structure` |
| N-10 | `n ≠ len(members)`, as a disagreeing array head | V5 `encoding` |

**SPEC-0002 V8 owns `1 ≤ k ≤ n`.** `n = len(members)` holds by construction:
there is no `n` field to disagree. Member order in these vectors is bytewise by
kid, which nothing requires yet (`ADR-0004` condition 5).

For DEC-002's acceptance test: `ArtifactStatement` is TV-4, `AuthzCert` is TV-5
and TV-9, and `NameCert` is TV-13 under DV-2 (`ARCH-0002` P6). Reasoning:
`design-log/0019-threshold-fixture/`.

## Locator target withdrawn

**N-11** is TV-4's attestation with `this = [5, uri]`. SPEC-0002 0.6.0 withdrew
target type 5, because a locator binds no digest (`ARCH-0001` R-M-07, R-M-11;
mofn#144). It is well-formed and correctly signed, so only V7 `structure` can
reject it. Reasoning: `design-log/0030-locator-digest/`.

## Delegation and the evaluations block

TV-14…20 are trust and attestation statements under TV-5's
`may-delegate {depth: 1, ranges: [reproducible]}`. `vectors.json` →
`evaluations` gives E-1…E-4: the statement set, the ask, and the SPEC-0004
answer, reason and failing statement. These are **declared**, not computed by
this script; `prototype/wallet/tests/test_delegation.py` checks them
(SPEC-0004 Appendix A asks 3–6; mofn#136).

| eval | case | expected |
|---|---|---|
| E-1 | hop `about` outside `ranges` | no, `widening` |
| E-2 | the same hop within `ranges` | yes |
| E-3 | a second hop with no delegation left | no, `depth` |
| E-4 | onward `depth` larger than what remains | no, `widening` (not clipped) |

After regenerating, copy `vectors.md` into SPEC-0002 between the
`VECTORS:BEGIN` / `VECTORS:END` markers.
