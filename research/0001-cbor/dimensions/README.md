# Raw dimension surveys

**These are unverified agent outputs, archived as evidence.** Six agents ran in
parallel on 2026-09-22, one per dimension. Each file carries its own `Sources`
section with retrieval dates and its own "what I could not verify" section.

They are kept because the finding is worthless without its basis — see
`library/docs/construction.md`, which was written from research that was then
discarded.

**Do not cite these directly.** `../report.md` is the reviewed artifact. Three
substantive claims in these files were checked against primary sources and
**rejected**; see report §9. Where a dimension file and the report disagree,
the report is right and the discrepancy is deliberate.
