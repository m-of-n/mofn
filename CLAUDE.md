# m-of-n

Key-centric semantic assertions. Read this before touching anything.

## The one rule

`spec/ARCH-0001-authorization-attestation.md` is the **source of truth** for the
architecture. Everything else defers to it. Read it before proposing anything.

**DEC-001 … DEC-005 and DEC-007 are open.** No encoding, tag language, or
envelope has been selected. Do not write code or documents that assume one.

## Never

- **Never mark a DEC-* accepted** anywhere except an `ADR-NNNN` file, with a
  changelog line and a status update in ARCH-0001. Not in a PR description, not
  in a commit message, not in a comment.
- **Never write a parallel architecture document.** ARCH-0001 §9.4 forbids it.
  Propose a diff against the file — see the `propose-arch` skill.
- **Never edit `docs/`.** It is generated by `bin/build-site` and gitignored.
  Edit `spec/` or `project/`.
- **Never bump `version` without `updated`.** ARCH-0001 §9.5; CI enforces it.
- **Never generate cryptographic primitives.** Vetted libraries only. AI
  assistance applies to specification, schema, encoding, mappings, vectors and
  tooling — never to primitives.
- **Never commit a third-party PDF, spreadsheet or ebook.** Record the digest
  and locator; see `library/CLAUDE.md`.

## Layout

| | |
|---|---|
| `spec/` | ARCH, ADR, MAP, `schema/`, `vectors/` — normative, authored |
| `project/` | PLAN, BACKLOG, PROC — execution, authored |
| `docs/` | **generated**, gitignored |
| `src/` | empty on purpose — DEC-002 is open; code now decides it by accident |
| `prototype/` | throwaway spikes; never ships |
| `design-log/` | AI-assisted design record — see below |
| `library/` | submodule; has its own `CLAUDE.md` |

"Artifact" is a **normative term here** (`ArtifactId`, `ArtifactStatement`,
R-M-07). Do not use it for files, documents, or build outputs.

## Before any PR

```sh
bin/validate-archdoc && bin/lib-sync --check && (cd library && bin/validate && bin/export)
```

Branch, worktree and review rules: `CONTRIBUTING.md`. Agents get their own
worktree — `bin/wt new <branch>` — so edits cannot collide.

## The design log is not optional

The project claims **AI-assisted protocol design** as a contribution. That is
only a contribution if it is instrumented. Any agent producing specification
text, schema, mappings or vectors writes a `design-log/NNNN-slug/` entry:
question asked, what was produced, what a human accepted or **rejected and
why**. Write up the rejections — that half is what makes the claim credible.
