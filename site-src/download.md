# Download

!!! warning "Prototype pre-releases"
    These builds exist to demonstrate the design. The architecture is a draft
    with open decisions; **do not use real keys** and do not rely on a verdict.

The wallet is published as GitHub pre-releases — a macOS desktop app and a
command-line build for macOS and Linux — each with `SHA256SUMS` and build
provenance.

- **Releases:** [github.com/m-of-n/mofn/releases](https://github.com/m-of-n/mofn/releases)
- **How to download, check and run it:** [Install the wallet](project/APP-0005-install-wallet.md)

Check the digest before you run anything. The install page shows how.
